# Star Wars API for Code The Dream

This project is a simple Star Wars data viewer that fetches information from the Star Wars API (SWAPI) at https://www.swapi.tech. It retrieves the first ten characters from the Star Wars universe, along with the films they appear in, and displays everything dynamically on the client side. The goal is to demonstrate clean API consumption, asynchronous JavaScript handling, and user‑friendly data rendering in a lightweight front‑end application.

## How to run it

- Fork or clone the repository
- Open the project folder
- Run the `index.html` file directly in your browse
